# Manju Ramalingam — Portfolio

Simple personal portfolio website (HTML, CSS, JavaScript).

## Open locally

Open `index.html` in your browser, or run:

```bash
npx serve .
```

## Structure

```
index.html      — page content
css/style.css   — styles
js/main.js      — mobile menu + year
assets/         — profile photo
```

## Deploy

Push this folder to GitHub and enable GitHub Pages (Settings → Pages → Deploy from branch → `/` root).
